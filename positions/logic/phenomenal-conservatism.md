# Phenomenal Conservatism (Justification of Deduction; e.g. Modus Ponens)

It has to be stated clearly that this justification is meant in the **epistemological** sense, with all the pros and cons that carries. It is meant in contrast to justification understood as "derivability" in logic — a completely different line of inquiry. Therefore, when discussing logic, this should be deployed as a supplementary argument alongside the canonical positions of logicians.

In the epistemological sense, this justification is, for example, different from truth (a belief can be justified yet false), defeasible (warrant can be undercut by new seemings or evidence), and even agent-specific (two reasoners with different background seemings can be differently justified about the same proposition).

I justify deductive laws via Phenomenal Conservatism (PC): *if it seems to S that P, then in the absence of defeaters, S thereby has at least some prima facie justification for believing that P*. Applied to deduction, the seeming that modus ponens preserves truth, that LNC holds, that a given proof is valid, *is itself* the foundational warrant. We do not justify deductive laws by inference at all — the intellectual seeming is the terminus, not a stage in an argument.

Defeasibility is obvious from one historical example: the naive comprehension axiom (or unrestricted comprehension) is a foundational principle of early, intuitive set theory stating that for any property there exists a set containing exactly the elements that satisfy that property. This is now considered false, but it *seemed* "obvious" when set theory was in development, and therefore NCA had prima facie justification (in the epistemological sense).

The argumentative outline is:

- **Intellectual seemings are foundational justifiers.** PC treats rational seemings on a par with perceptual ones. When you entertain modus ponens or the law of non-contradiction, the principle *seems* compelling on reflection. That seeming, by PC, is itself prima facie sufficient for justified belief — no further derivation required.
- **Carroll's regress dissolves.** Lewis Carroll's tortoise shows you cannot justify MP by adding it as a premise — you would need a further rule to license that move, ad infinitum. Susan Haack sharpens this into a dilemma: any putative justification of deduction is either circular (using deduction) or impotent (using induction). PC denies that the demand for such a justification is well-formed in the first place. The seeming itself is foundational, so the regress never starts.

**Usage:** Supplementary argument, not the headline thesis. This is an epistemological move added alongside the canonical logical answer (meaning-theoretic derivation, proof-theoretic justification, etc.) — not a substitute for it. Restrict to roughly a quarter of any answer to a question about the justification of logical laws; the canonical position of logicians remains the main line of argument. You can make PC an informal conclusion of an essay if the question states "justification", but if we are in Logic course, content has to show knowledge of arguments in Logic course, not Epistemology.
