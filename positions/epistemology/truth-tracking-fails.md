# Truth-Tracking Fails

Nozick's sensitivity condition is one more failed analysis. It violates closure (you'd know you have hands but not that you're not a BIV) and faces standard counterexamples. Reject sensitivity/tracking analyses.

**Applicable to:** Nozick, truth-tracking, counterfactual sensitivity, sensitivity condition, Dretske conclusive reasons, *epistemology / 2. Truth-Tracking, Belief, and Knowledge as Primitive*
