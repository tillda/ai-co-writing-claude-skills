# Logic (PY1070)

The PY1070 subject guide (R.M. Sainsbury, University of London, 2012) is the syllabus document and the only required text supplied with the course; it is a short orienting guide rather than a textbook. Citations should go to the canonical sources listed at the top of each module (where the Guide names them) and to the deepening Readings drawn from the Guide's master bibliography. Modules below mirror the Guide's chapter structure, with module 0 added to capture introductory material on validity, monotonicity, and the place of logic in rationality.

**Topics:**
