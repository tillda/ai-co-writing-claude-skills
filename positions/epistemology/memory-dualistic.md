# Memory: Dualistic (UK ch. 11)

A remembered belief is justified iff it was rationally acquired *and* is being rationally retained. Reject the pure preservation theory (it implausibly justifies beliefs after a Five-Minute-Hypothesis-style reset). Reject the pure foundational theory (it makes memory a generative source). Reject the pure inferential theory (it overintellectualises ordinary remembering).

**Applicable to:** memory, preservative memory, generative memory, Lackey memory generative, memory knowledge, do we need positive reasons to trust memory, forgotten evidence, *epistemology / 6. Testimony and Memory*
